UBPorts has announced the release of Ubuntu Touch 24.04-2.0 based on Ubuntu 24.04. It features an upgraded Morph Browser based on Chromium 134, supports smartphones with notches and rounded corners, a Widevine DRM installer, and more.

Ubuntu Touch 24.04-2.0 highlights:

  • Updated browser engine for Morph Browser from Chromium 87 to Chromium 134 for improved compatibility with websites and web applications
  • Installer for Widevine DRM with the following note:

    Widevine installer is not endorsed by Google. UBports, Ubuntu Touch, or Morph Browser is not a licensed Widevine implementation. Extracting Widevine from another source is considered by some to be in legally grey area. You are responsible for your usage of Widevine installer.

  • Support for notches and rounded corners; currently configured on Fairphone 4 and 5, all Volla devices, and several community devices
  • Screenshot editor allowing users to crop, rotate, and adjust color; this can be disabled by the user
  • Ubuntu Touch now supports printing documents directly from the device; it’s not enabled by default, and you’ll need to go to System Settings > Printing.
  • Support for legacy (X11-based) applications from Open-Store is improved
  • Network indicator is improved to handle wired connection (e.g., through a dock)
  • Improved mobile data connection reliability
  • User data encryption for newer devices supporting fscrypt v2
  • Added support for Georgian language (keyboard)
  • ~2,000 new emojis are added to the emoji keyboard
  • Various bug fixes and security updates

One downside of the Ubuntu Touch 24.04-2.0 is its increased system storage space requirements, so the number of supported devices has been reduced. The project released a list of phones supported by the new version of Ubuntu Touch:

  • Asus Zenfone Max Pro M1
  • F(x)tec Pro1 X
  • Fairphone 4 and 5
  • Lenovo Tab M10 HD 2nd Gen WiFi / LTE
  • OnePlus Nord N10 5G and N100
  • Rabbit R1
  • Sony Xperia X
  • Volla Phone, Phone X, Phone 22, Phone X23, Phone Quintus, and Phone Plinius
  • Xiaomi Poco X3 / X3 NFC, Redmi 9 and 9 Prime, Redmi Note 9
  • Zinwa Q25 (new)

A few more details, including known issues like the lack of hardware video decoding in the Morph browser, may be found in the announcement. Existing Ubuntu Touch users can upgrade directly from their phone, with a 2-step upgrade: first to 24.04-1.4, then to 24.04-2.0. New Ubuntu Touch users will find instructions for installing Ubuntu Touch on their device at https://devices.ubuntu-touch.io.
